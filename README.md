## Sobre

Trabalho de Conclusão de Curso do técnico em Desenvolvimento de Sistemas da **ETEC Professor Basilides de Godoy** (2024): um e-commerce voltado para hardware gamer, desenvolvido em grupo.

> "Esse sistema foi realizado por um grupo que pra mim é o *dream team*. Foi um projeto bem difícil, mas que conseguimos realizar com êxito." — Luis Roberto

### Sobre este repositório

O código-fonte **não está versionado aqui**. Por ser um projeto grande, ele foi disponibilizado para download no Google Drive (`ProjetoGameFest.zip`). Este repositório reúne a documentação, o link de download e o vídeo de demonstração do sistema.

## Como rodar localmente

**Pré-requisitos**

- [MySQL Workbench](https://dev.mysql.com/downloads/installer/)
- [Visual Studio Code](https://code.visualstudio.com/)

**Passo a passo**

1. Baixe o projeto pelo [link do Google Drive](https://drive.google.com/file/d/1RxK6j0if1vkImUcf9xDfDzPdZaIakSwc/view?usp=sharing) e descompacte o arquivo.
2. Baixe o banco de dados do projeto e execute-o no MySQL Workbench.
3. Abra o projeto e execute-o.

> Recomenda-se usar o **Google Chrome** ou o **Microsoft Edge**.
